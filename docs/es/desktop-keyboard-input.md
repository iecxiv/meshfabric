# Eventos nativos de teclado del escritorio

[English](../desktop-keyboard-input.md) | Español

Solo para el escritorio, basado en dev/main 2f61dbf. El campo de texto oculto existente intercepta ahora las pulsaciones y liberaciones de teclas Android reconocidas antes del procesamiento predeterminado del cursor y del foco; las teclas consumidas no se envían también mediante ediciones de texto. El foco para el teclado físico no requiere abrir el teclado virtual. Los callbacks de texto del IME y el transporte Unicode se conservan, no se reescriben. Las pruebas envían flechas marcadas como procedentes de teclado virtual, además de Ctrl/flechas/F12 físicos; no prueban el APK real de Hacker's Keyboard.

El mapeo cubre letras, dígitos, puntuación OEM, flechas, Tab/Intro/Escape, Retroceso/Supr, Insert, Inicio/Fin, RePág/AvPág, F1–F12, teclado numérico, bloqueos, ImprPant/Pausa, modificadores y menú contextual cuando Android entrega esos eventos. Los modificadores izquierdo/derecho se normalizan a códigos VK remotos genéricos. Las teclas pulsadas se cuentan por referencias; las repeticiones generan pulsaciones adicionales sin liberaciones extra; los modificadores implícitos de meta se equilibran. Perder el foco, la actividad, la conexión o el control de entrada por un diálogo provoca un intento de liberar las teclas registradas sin reproducirlas. Inicio/Atrás/encendido/volumen del sistema Android y los códigos desconocidos siguen su ruta habitual. ACTION_MULTIPLE no admitido se deja a la ruta de entrada existente.

Limitaciones: no se garantiza universalmente la distribución remota, AltGr, estados de bloqueo/teclado numérico, modificadores por lado, comportamiento Unicode/composición, mezcla con la barra de herramientas, juegos o consumidores de códigos de exploración, combinaciones protegidas del sistema operativo ni atajos interceptados por Android. Los emisores existentes de teclas individuales, combinaciones y texto no cambian. No se rediseñan el protocolo ni el portapapeles, ratón, terminal o versión. Liberar una tecla cuando el transporte ya está roto no garantiza que el sistema remoto reciba su liberación.

CI compila la app y sus pruebas, ejecuta pruebas JVM de mapeo/estado, pruebas nativas de despacho Compose y regresiones existentes del terminal. Sigue siendo necesaria la validación en dispositivos con Hacker's Keyboard, un teclado físico y equipos Windows/Linux, especialmente idiomas/acentos, texto del IME, modificadores mantenidos, repeticiones y recuperación tras pérdida de foco o desconexión. No se añade registro del contenido de las teclas.
